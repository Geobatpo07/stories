## Decisions and quirks, flagged rather than folded in

1. **TS bug kept.** `friendlyRelationshipMessage` searches for `points to missing target`, but the Kernel's error says `has a dangling reference in`, so the regex never matches and every relationship failure shows the generic text. Ported as-is and pinned by a test. A fix is a separate decision.
2. **`min(8)` counts UTF-16 code units** (four emoji pass in zod). Ported exactly (`utf16_length`), verified against real zod.
3. **No `NODE_ENV` in Python.** `STORIES_ENV` (`production` / `development` / `test`); unset means production on Vercel (`VERCEL` set) and development elsewhere. This drives the cookie `Secure` flag, the Studio flag and the limiter fallback. It is an adaptation, pinned by tests, not a TypeScript behaviour.
4. **Rate limiter**: same design as the hotfix (IP from `x-real-ip` only when `VERCEL=1`; development skips; production without a trusted IP uses one shared fail-closed bucket; never the email).
5. **`/api/authoring/definitions` is gated** like the documents routes (404 when the Studio is off, then 401) and returns the bare list that `definitions.json` holds. The task did not specify the gate; this is the conservative choice.
6. **Publishing is stubbed in two places** (`UnimplementedPublicationTarget`, `revalidate_site`), both raising `NotImplementedError`. Because the TS route turns every failure into 422, the stubbed route answers 422 `Publishing is not implemented...`. The seam is `PublicationTarget.publish(rendered, previous_path) -> report` and an async revalidate hook.
7. **`materialize_authoring_objects` does not build the knowledge graph** (the TS function does); nothing reads it.
8. **Sort order of drafts** uses a `localeCompare` approximation (case-insensitive, lowercase first on ties). Exact for UUIDs and ISO timestamps; not verified against ICU for arbitrary strings.
9. **Corrupt stored rows and malformed JSON raise** (HTTP 500), as in TypeScript.
10. New generators (new files, no existing TS changed): `backend/tools/render-mdx-cases.mts`, `backend/tools/zod-string-cases.mjs`; they regenerate their fixtures byte-identically.
