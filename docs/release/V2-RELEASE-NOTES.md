# Stories Platform V2

Stories Platform V2 is the first production-ready release of the Digital Research
Laboratory. It presents research as a connected progression from Programs to Projects,
Stories, and Artifacts while keeping the underlying platform invisible.

## Highlights

- Verified Runtime startup from generated manifest and DuckDB artifacts.
- Complete public directories and detail records for every research concept.
- Instant, keyboard-first search across the laboratory.
- Consistent parent, children, previous, next, related, and breadcrumb navigation.
- Publication-quality stories with progress, contents, GFM tables, footnotes, references,
  code controls, KaTeX mathematics, captioned figures, and image zoom.
- Dedicated laboratory overview and chronological research timeline.
- Light, dark, system, responsive, reduced-motion, and print presentations.
- Static knowledge pages and minimized client interaction payloads.
- Canonical metadata, social cards, scholarly JSON-LD, structured breadcrumbs, RSS,
  sitemap, and robots.
- Documented authoring, development, deployment, maintenance, and release procedures.

## Public vocabulary

Scientific Questions are presented as Projects. Notes are presented as Stories.
Publications, Datasets, Software, and Presentations form the Artifact collection.
Hypotheses and Experiments remain within their Project investigation record.

## Compatibility

Version 2 requires Node.js 20.9 or newer and pnpm 9 or newer. Existing Sprint 1–4 source
content and generated schema remain compatible; no new domain or storage architecture was
introduced.

## Deferred work

AI, LLMs, embeddings, vector search, graph visualization, authentication, comments,
collaboration, editing, administration, and notifications remain intentionally absent.
