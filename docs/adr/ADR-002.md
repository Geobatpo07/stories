# ADR-002: Knowledge Objects are the source of truth

- **Status:** Accepted
- **Date:** 2026-08-03
- **Supersedes:** ADR-001 source-of-truth decision

## Context

Stories Platform V3 introduces a private Knowledge Authoring Studio. Authors need drafts,
autosave, schema-generated forms, relationship selection, friendly live validation, and
multiple future publication formats. Treating MDX as both editing interface and canonical
model cannot support that lifecycle without duplicating domain rules.

## Decision

Canonical Knowledge Objects stored under `knowledge/` are the source of truth. They contain
the entity kind, partial or validated schema fields, narrative content, authoring timestamps,
publication state, and the last publication record.

MDX is a deterministic publication artifact generated by `MDXRenderer`. DuckDB and
`manifest.json` remain generated Runtime artifacts. Git versions both canonical Knowledge
Objects and published MDX, preserving the publication audit trail.

## Consequences

- Draft saves update only canonical JSON and never produce public content.
- Publishing reuses Kernel schemas, normalization, and relationship resolution.
- Publishing generates MDX, executes the existing artifact pipeline, and rolls back the MDX
  change if artifact validation fails.
- The public website remains unchanged: it consumes Platform Runtime artifacts only.
- Manual MDX editing remains possible for emergency maintenance, but the canonical object
  must be reconciled before the next Studio publication.
- The local filesystem adapter is intended for a private Git workspace. Public or serverless
  deployment requires a durable `PersistencePort` adapter and access control.
